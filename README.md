# Homam Khoshaim - Somfy RTS Board


## Description
The project requires developing a SomfyPlus HomeKit controller that can control Somfy RTS blinds through HomeKit in client's home. The instructions and programming requirements are laid out in [this](https://github.com/HomeSpan/SomfyPlus) repository

## Project Requirements
The steps for the project are:
* Review the provided link, get the hardware (or similar hardware if not exact part is not available), assemble it and flash it with the relevant code
* Test it (or verify that it is indeed working) and then prepare for shipment. 
* The desired behavior is that produc should be able to add RTS remote channels (up to 32 different channels) to the device through the finished product (see step 5 of the link). 
* The device is mean to be used by non-technical users/end-users and should function as per the link.
* The device should be enclosed in 3d printed case/looks presentable and is user friendly (i.e. buttons are mapped and marked)
* The device should have a long range antenna.
